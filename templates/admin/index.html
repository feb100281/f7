⚙ Как работают команды
  1. Команда — это management-команда Django: python manage.py <команда>.
  2. Параметры задаются в карточке команды (JSON) — пути к файлам, даты, лимиты.
  3. Запуск — кнопка «Запустить» в списке: задача идёт в фоне, статус меняется сам.
  4. Лог — «Открыть лог»: весь вывод команды с отметками старта и результата.
